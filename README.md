# Import Data Using Transform Maps (Spreadsheet) in ServiceNow

## 📌 Project Description

This project demonstrates how to import data from a spreadsheet (Excel or CSV) into the ServiceNow platform using **Import Sets and Transform Maps**.

The project focuses on importing external data into ServiceNow tables, mapping source fields to target fields, and transforming the data accurately. Transform Maps help ensure that spreadsheet data is transferred to the appropriate ServiceNow fields.

This project provides practical knowledge of ServiceNow data import functionality and basic data management.

## 🎯 Objectives

- Import data from spreadsheets into ServiceNow.
- Create and configure Import Sets.
- Create Transform Maps to map source fields to target fields.
- Transform and load data into the target table.
- Understand the basic ServiceNow data import process.

## 🛠️ Technologies Used

- **Platform:** ServiceNow
- **Feature:** Import Sets
- **Feature:** Transform Maps
- **Input Format:** Excel / CSV Spreadsheet
- **Data Processing:** Field Mapping and Data Transformation

## ⚙️ Project Workflow

1. Prepare the data in an Excel or CSV spreadsheet.
2. Upload the spreadsheet into ServiceNow.
3. Create an Import Set to hold the imported data.
4. Configure a Transform Map.
5. Map the source fields to the corresponding target fields.
6. Run the transformation process.
7. Verify that the data has been imported correctly into the target table.

## 📋 Key Features

- Spreadsheet-based data import.
- Source-to-target field mapping.
- Automated data transformation using Transform Maps.
- Data loading into ServiceNow tables.
- Validation of imported records.
